# SeriesWorld

SeriesWorld es una aplicación web que permite consultar información sobre series de televisión utilizando la API pública de TVmaze.

El proyecto fue desarrollado como parte de un curso de Front-End para practicar el consumo de una API, el manejo del DOM y la creación de una interfaz responsive utilizando HTML, Sass y JavaScript.

## Funciones principales

- Mostrar un catálogo de series.
- Mostrar una serie destacada.
- Buscar series por nombre.
- Consultar la calificación, los géneros y el estado de cada serie.
- Abrir una ventana con información más detallada.
- Mostrar mensajes de carga, error y búsquedas sin resultados.
- Adaptar el diseño a diferentes tamaños de pantalla.

## API utilizada

Este proyecto utiliza la API pública de TVmaze:

https://www.tvmaze.com/api

## Cómo utilizar el proyecto
- Descarga o clona el repositorio.
- Abre la carpeta del proyecto.
- Abre el archivo index.html en el navegador.
- Espera a que aparezcan las series del catálogo.
- Escribe el nombre de una serie en el buscador.
- Presiona el botón Buscar.
- Presiona Ver detalles para consultar más información.
- La aplicación necesita conexión a Internet para consultar la API de TVmaze y cargar Axios.
